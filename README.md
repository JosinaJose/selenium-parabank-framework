# 📘 Selenium Automation Framework – Parabank Application
This project demonstrates an end-to-end automation framework for the Parabank demo site using Java, Selenium WebDriver, and TestNG. It follows the Page Object Model (POM) design pattern and supports cross-browser testing, data-driven testing, logging, and reporting.

### ✅ Features
* Page Object Model (POM) for maintainable and scalable code
* Cross-Browser Testing (Chrome, Firefox, Edge)
* Data-Driven Testing using Excel sheets
* Centralized Configuration Management using ReadConfig.java
* Reusable BaseClass for setup, teardown, logging, and screenshots
* ExtentReports Integration for detailed HTML test reports
* Screen Recording during test execution
* Screenshot Capture on test failures
* Log4j Logging Support
* TestNG Framework for test structure and execution flow
* Maven for dependency management and project builds


### 📄 Technologies Used
* Java 21+
* Selenium WebDriver
* TestNG
* Apache POI – Excel file handling
* ExtentReports – Test reporting
* Log4j – Logging
* Maven – Build and dependency management
* ATU/Monte Media – Screen recording (optional)
* Log4j for logging support
